# 🍈 メロン日記

生徒たちのメロン栽培のようすを集めた、**フォトギャラリー付きのホームページ**です。
写真ギャラリーに加えて、メロンの説明・栽培カレンダー・豆知識まで、まるごとメロン一色でまとめています。

HTML / CSS / JavaScript だけで作られているので、**サーバーは不要**。
`index.html` をブラウザで開くだけで表示できます。

---

## 📄 ページの内容

| セクション | 内容 |
| --- | --- |
| メロンって？ | メロンがどんな果物かをやさしく紹介 |
| フォトギャラリー | 栽培写真を一覧表示（カテゴリで絞り込み・クリックで拡大） |

| 豆知識 | 知って楽しいメロンのひみつ |
| 生徒の声 | 育てた生徒たちのコメント |

## 📷 写真を追加する方法

いちばん大事なフォトギャラリー。写真の追加はとても簡単です。

### 1. 写真ファイルを入れる

撮った写真を `images/` フォルダに入れます。
（例：`images/mizuyari.jpg`）

> ヒント：ファイル名は英語・数字がおすすめです（例 `harvest01.jpg`）。
> 写真は長辺 1200px くらいに縮小しておくと、表示が軽くなります。

### 2. `js/gallery-data.js` に1行足す

ファイルを開き、`GALLERY_PHOTOS` の中に写真の情報を追加します。
既にあるブロックをコピーして、3か所を書き換えるだけです。

```js
{
  src: "images/mizuyari.jpg",        // ← 写真ファイルの場所
  caption: "みんなで協力して水やり",   // ← 写真の説明
  category: "care",                   // ← カテゴリ（下の表から選ぶ）
},
```

### 3. カテゴリの選び方

| category に書く言葉 | 意味 |
| --- | --- |
| `seed` | 種まき・苗 |
| `care` | 日々のお世話 |
| `grow` | 実りの様子 |
| `harvest` | 収穫・試食 |

これで完成！ ブラウザで `index.html` を開き直すと、写真が追加されています。

> 最初から入っている `placeholder-*.svg` はサンプルのイラストです。
> 本物の写真を追加したら、`js/gallery-data.js` から不要なサンプルの行を消してください。

## 🎨 文章やデザインを変えたいとき

| 変えたいもの | 編集するファイル |
| --- | --- |
| 見出し・説明文・豆知識などの文章 | `index.html` |
| 色や見た目 | `css/style.css`（上の方の `:root` で色をまとめて変更できます） |
| ギャラリーの写真 | `js/gallery-data.js` |

## 📁 ファイル構成

```
melon/
├── index.html            … ページ本体
├── css/
│   └── style.css         … デザイン
├── js/
│   ├── gallery-data.js   … ギャラリーの写真リスト（ここを編集）
│   └── main.js           … ギャラリーや拡大表示の動き
├── images/               … 写真・イラストを入れる場所
└── README.md             … この説明ファイル
```

## 🌐 インターネットに公開するには

GitHub Pages を使うと無料で公開できます。

1. このリポジトリの **Settings → Pages** を開く
2. **Build and deployment** の Source を「Deploy from a branch」にする
3. Branch を公開したいブランチ（例 `main`）／`/root` に設定して保存
4. 数分待つと表示される URL でホームページが公開されます
